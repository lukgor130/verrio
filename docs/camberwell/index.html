Tax treatment included

Standard residential SDLT is used because the session specified UK-resident, non-first-time buyer, primary residence. Rent-a-Room relief shelters the first £7,500 of lodger income. Private Residence Relief is assumed to remove CGT on sale if the property remains the main home throughout.

What would change the answer

Trust structure, leasehold service charge, major works, exact council-tax borough, lodger vacancy, and a worse London flat market all matter. The model is intentionally price-sensitive so stretching past the cash envelope is visible immediately.
